# Task 3 - UIET Startups Showcase Page

A responsive page showing startup cards, with search and category filtering, built with plain HTML, CSS, and JavaScript.

## Features

- Startup cards showing name, category, short description, and a website link
- Search box filters cards live as you type
- Category filter buttons (All / EdTech / EV / FinTech)
- Hover animation on cards (lift + shadow)
- A form to submit a new startup, adds a new card to the page instantly, no reload or backend needed
- Responsive layout for mobile and desktop

## Files

- `index.html` - page structure
- `style.css` - styling and hover animations
- `script.js` - search, filter, and add-startup logic

## How to run

1. Download all three files (`index.html`, `style.css`, `script.js`) into the same folder.
2. Open `index.html` in any browser.
3. No installation or server needed, it's a static page.

## Tech used

HTML, CSS, vanilla JavaScript (no frameworks or libraries).
